Data backup & device sync

Data is stored only on this device. To move data between phone and tablet (or tablet to tablet): download a backup, send the file to the other device, load it there, then choose Combine or Replace.

⚠ Replace overwrites everything already on this device with the backup file. Combine permanently adds entries from the file and changes stock levels. Neither can be undone by hand. A safety copy of this device is saved automatically first, and you can bring it back from Backup history below (only the last 3 safety copies are kept).
